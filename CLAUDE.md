# Site e downloads do Cortes

Este repositório é público e só tem duas coisas: o site de apresentação (`index.html`, publicado pelo GitHub Pages em https://franksilva01.github.io/cortes-app/) e as releases com os instaladores.

- Publicar o site: `git push origin main`. O Pages leva cerca de um minuto para atualizar; para conferir sem cache, abra o endereço com `?v=N` no fim.
- O site é um arquivo só, sem etapa de build. Fontes pelo Google Fonts. Tem `noindex` até o dono decidir divulgar.
- Os botões de download apontam para `releases/latest/download/`, então a release marcada como mais nova é a que o site e o programa usam.
- Nada de código do programa entra aqui. O código, as regras do projeto e o passo a passo de publicação estão no `CLAUDE.md` do repositório privado `FrankSilva01/cortes`.
