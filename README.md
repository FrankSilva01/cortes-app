# Cortes

Programa para Windows que transforma gravações de gameplay em Shorts prontos, no seu PC.

**Baixar:** https://franksilva01.github.io/cortes-app/

A página pergunta qual é a sua placa de vídeo (NVIDIA, AMD ou Intel) e entrega o instalador certo. Os arquivos também ficam em [Releases](https://github.com/FrankSilva01/cortes-app/releases/latest).

Versão de teste para convidados.
