# Cortes

Programa para Windows que transforma gravações de gameplay em Shorts prontos, no seu PC.

**Baixar:** https://franksilva01.github.io/cortes-app/

Um instalador só (`CortesSetup.exe`), para placa NVIDIA, AMD, Intel ou PC sem placa de vídeo. Os arquivos também ficam em [Releases](https://github.com/FrankSilva01/cortes-app/releases/latest).

Versão de teste para convidados.
